# Mola Tea

Mola Tea is a seven-day text management game exposed through the shared
Learn2Play Bench interface.

```bash
python play.py mola_tea --seed 1 --episode 1 --lang en
```

The game advertises complete state-dependent commands. Recipe-card attributes,
product IDs, group IDs, merchandise IDs, prices, costs, and stock are shown in
the opening or `status` output.
