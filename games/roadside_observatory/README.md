# Roadside Observatory

You are guiding a traveler to a mountain observatory before the comet window
closes. Each turn, choose where to go or how to handle an encounter. Manage
energy, supplies, cash, time, and attention.

The route changes across episodes: traveler names, stops, items, route details,
and people along the road are reshuffled. The world has patterns, but they are
not explained. Learn from repeated journeys.

Run it through the shared interface:

```bash
python play.py roadside_observatory --seed 42 --episode 1 --lang en
```

Common actions include:

- `walk main road`
- `walk scenic trail`
- `take bus`
- `hitch safe`
- `hitch risky`
- `rest`
- `forage`
- `check map`
- `observe person`
- `ask route`
- `listen`
- `leave`
